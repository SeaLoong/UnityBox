# ASS 0.9.6：生成状态统一 WD On

本版全部 ASS 新状态固定使用 WD On，不检测或匹配原 FX。范围包含密码、倒计时、
音频、生命周期、释放、防御、混淆、诱饵及 ASS 新建默认 Idle。原有用户状态的 WD、
动画及源资源保持；隐藏的历史 `writeDefaultsMode` 字段继续保存原值。

## 表情残留与修复

原 WD On 表情将 BlendShape 设为85，再切回空 Clip 或无 Motion 的 Neutral 时，原图
依靠 WD 回到0。0.9.5 固定追加的 ASS WD Off 层会让权重停留在85；仅将 ASS 新状态
改为 On 后归零。此前完成的18组原生对照保存在本目录的 baseline-off 子目录。

当前原生回归直接调用生成 API，不在测试中修改生成状态的 WD。六组对照覆盖原图
On/Off、空 Clip、无 Motion和显式归零曲线；先检查原图，再检查合成图。原 Off 图的
空 Neutral 保持85，显式归零曲线仍回到0，源 Controller/Clip/Mesh 和 metadata 逐字节保持。

NDMF 回归通过实际调度和 Finish，检查空 Clip/无 Motion、警告音开关的四种最终图，
表情85→0，同时保留上游 Light、下游 Audio、原用户图及 SDK 音频校验。

## 流程与测量

完整功能范围使用 Unity2022.3.22f1、UTF1.1.33、SDK3.8.2；完整依赖增加 NDMF1.11、MA1.18。
每个工程仅选择 ASS 包。功能范围排除性能和图形分类，测试完整程序集；各范围包含重复用例。

生成后检查密码连续保持、超时、成功、释放和 Restart；检查全部生成层独立求值、新状态On，
用户原状态与字段保留。额外反馈对照读取 Overlay/警告音/成功音对象和倒计时属性。
Player 与性能在其它 Editor 停止后串行执行；性能记录包含实际规模、预热、样本和计数器可用性。

[执行记录与源码指纹](evidence.json)包含命令、真实 NUnit/XML/DLL/源码 SHA、Player 和测量。
音频继续使用0.9.5的固定 metadata及后台加载设置，验证历史见[音频记录](../ASSAudioUpload/README.md)。

正常更新包并重新构建即可生成新的 WD On 副本；打开项目、加载资源和导入不改写用户图。

## 全库基线

全库八插件的历史功能、图形与串行测量继续对应 `7cd4b40`；本次 ASS 专项按新版本、
命令及源码指纹单列。原始音频上传专项对应0.9.5，不将旧运行标签改成新版本。

同时修复原 TimeUp→Release 无 Exit Time/条件、被 Unity 忽略的转场；补上有效 TimeUp
条件，并为计时/音频添加本地 Restart 优先入口。原生验证两轮真实超时、重启后的进度
重新下降与警告音恢复。WD On 在成功/超时退出后恢复进度默认值；超时覆盖和音频对象关闭。
